    Quick theory

    DFA: one next state for every state-symbol pair. NFA: a set of possible next states. Both accept when the computation finishes in at least one final state.

    This exact-string automaton is built from the current input, 10101. Its accepting state is reached by reading 1 → 0 → 1 → 0 → 1 in order. The DFA adds a dead state (D) for any unexpected symbol, making its transition function total.
